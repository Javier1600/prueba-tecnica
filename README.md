Instrucciones rápidas:
1. Clonar el repositorio
2. Ejecutar: docker-compose up
3. Servicios disponibles:
   - ms-clientes:  http://localhost:8181
   - ms-cuentas:   http://localhost:8182
   - RabbitMQ UI:  http://localhost:15672 (admin/admin)
   - Swagger ms-clientes:   http://localhost:8181/swagger-ui.html
   - Swagger ms-cuentas:    http://localhost:8182/swagger-ui.html
